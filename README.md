# Sales Analysis Dashboard using Power BI

## 📌 Project Overview
This project focuses on analyzing sales data and presenting
key business insights through an interactive Power BI dashboard.

## 🎯 Project Objectives
- Analyze total sales and profit.
- Track sales performance using KPI cards.
- Explore sales trends over time.
- Analyze product and category performance.
- Understand sales distribution by location.
- Enable interactive filtering and drill-through analysis.

## 🛠️ Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel
- GitHub

## 📊 Dashboard Features
- KPI cards for key performance indicators
- Sales and profit charts
- Sales trend line chart
- Product and category analysis
- Geographic sales map
- Interactive slicers and filters
- Product-level drill-through
- Date-based analysis
